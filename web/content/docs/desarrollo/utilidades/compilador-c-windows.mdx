---
title: "Cómo usar Metasploit Framework Compiler para Windows para compilar código C"
description: Generar un ejecutable Windows a partir de código C embebido en el módulo.
---

Para casos donde un payload estándar no basta y se necesita un stub nativo a medida (por ejemplo, un pequeño ejecutable que haga una comprobación específica del entorno antes de decidir si ejecuta el payload real), Metasploit Framework incluye un compilador C cruzado que genera binarios `.exe` de Windows desde Linux/macOS sin depender de tener Visual Studio instalado.

```ruby
codigo_c = <<~C
  #include <windows.h>
  int main() {
    MessageBoxA(NULL, "ejemplo", "demo", MB_OK);
    return 0;
  }
C

exe = Msf::Util::EXE.to_win32pe_from_c_src(codigo_c)
file_create(exe)
```

Por debajo, el compilador usa una cadena de herramientas tipo MinGW empaquetada con el framework, por lo que no depende de que el sistema donde corre msfconsole tenga un compilador C para Windows instalado aparte. Esto se combina frecuentemente con [CRandomizer](/docs/desarrollo/utilidades/crandomizer) para ofuscar el binario resultante antes de entregarlo.
